# Potential Field Navigation Simulator

An interactive robotics simulation exploring autonomous navigation via vector
fields, gradient-based optimization, and potential functions. See
[CLAUDE.md](./CLAUDE.md) for the full phase roadmap.

## Stack

React + TypeScript + Vite, Tailwind CSS for styling, Canvas API for rendering,
math.js for vector/matrix utilities.

## Development

```bash
npm install
npm run dev
```

## Status

**Phase 1 — Project Foundation** (complete): React/TS/Vite + Tailwind setup,
Canvas rendering pipeline, fixed-timestep simulation loop, robot
representation, and a world-space/screen-space coordinate system with an
adjustable timestep control.
